## Pharmora

Sistem manajemen apotek berbasis web untuk menggantikan pencatatan manual (buku/spreadsheet) di apotek mandiri.

## Fitur
- Login Admin
- Kelola data obat (tambah, ubah, hapus, cari)
- Notifikasi obat mendekati/sudah kedaluwarsa
- Pemesanan obat ke supplier & penerimaan obat (stok bertambah otomatis)
- Kelola data pasien & supplier
- Pemberian obat berdasarkan resep (stok berkurang otomatis)
- Laporan bulanan (obat masuk, keluar, kedaluwarsa) dengan ekspor PDF

## Tech Stack
Java • Thymeleaf • HTML + CSS • MySQL • Figma (desain UI)
